# ZaffronRP Domstol v6

Denne version beholder det oprindelige ZaffronRP Domstol-design fra v2 og bruger det renskårne ZaffronRP-logo.

Serveren indeholder:
- offentligt sagsoprettelsesformular
- kontaktformular til dommer, Anklagemyndigheden og advokat
- login og indbakke
- personaleområde
- administrator kan ændre adgangskoder

Start lokalt med Node.js:
`node server.js`
Åbn derefter `http://localhost:3000`.

Initiale logins står i INITIAL_LOGINS.txt.

Bemærk: En offentlig internetadresse kræver hosting/server. Denne pakke udgiver ikke sig selv på internettet.
